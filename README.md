# Pincer
Local AI coding assistant for your terminal. Runs on Ollama — no API keys.
## Install
curl -fsSL https://raw.githubusercontent.com/nsfwhusnain-coder/pincer/main/install.sh | bash
## Commands
| Command | Description |
|---------|-------------|
| /model | Switch model |
| /think | Toggle thinking mode |
| /clear | Clear history |
| /compact | Summarize old context |
| /context | Show stats |
| /exit | Quit |
| /help | Show help |
